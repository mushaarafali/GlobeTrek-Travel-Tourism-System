# GlobeTrek – Travel & Tourism Management System

GlobeTrek is a web-based Travel and Tourism Management System developed to provide users with a centralized platform for exploring destinations, travel packages, transport services, travel guides, and customized travel experiences in Sri Lanka.

The project was developed as an academic software development project with a focus on structured application development, responsive user interfaces, database integration, and maintainable MVC architecture.

## Key Features

- User registration and authentication
- Travel destination and package browsing
- Travel guide information
- Customized trip planning
- Transport service management
- Booking management
- Payment functionality
- Customer inquiry management
- Administrative management features
- Responsive and user-friendly web interface

## Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
- MVC Architecture
- Git & GitHub

## Architecture

The application follows the Model-View-Controller (MVC) architectural pattern to provide clear separation between business logic, data management, and the presentation layer.

## Project Structure

- `app/controllers` – Handles application requests and business operations
- `app/models` – Handles application data and database operations
- `app/views` – Contains the user interface views
- `app/core` – Core MVC components
- `app/helpers` – Reusable application helper functions
- `config` – Application configuration
- `public` – Public assets and application entry point
